
# 设定问答与大纲规范

来源：整合 Chinese Novelist 的三层问答悬念钩子机制 + Oh Story 的确定性门禁思想。

## 一、三层问答初始化（通用网文必做）

每次开新书，无论用户是否给出题材，都先执行三层问答。目的是把"模糊灵感"固化为可写作的设定档案。

### 第一层 · 世界观（5-10 问）

必问项：
1. 故事发生在什么世界/时代？（现代都市 / 架空玄幻 / 未来科幻 / 混合）
2. 这个世界里最独特的规则是什么？（金手指来源、超凡力量体系、社会规则）
3. 力量体系如何运转？（等级、晋升条件、代价）
4. 主要舞台在哪里？（城市/宗门/学院/副本）
5. 有哪些势力组织？彼此什么关系？
6. 普通人如何看待超凡/主角所在群体？
7. 世界基调：轻松爽文 / 黑暗深沉 / 热血成长？

### 第二层 · 人物（5-10 问）

必问项：
1. 主角是谁？（身份、年龄、开局处境）
2. 主角最想要什么？（核心动机，必须具体可量化）
3. 主角最大的缺陷是什么？（性格缺陷或能力短板）
4. 主角的金手指/优势是什么？触发条件与限制？
5. 关键配角：盟友 1-2 个（怎么认识、互补什么）
6. 反派是谁？他的动机与主角的冲突点在哪？
7. 有没有感情线？对象是谁？发展节奏？

### 第三层 · 冲突（5-8 问）

必问项：
1. 全书主线冲突是什么？（一句话说清）
2. 中期最大危机是什么？（第 30-60% 处的转折）
3. 前三章每章的核心冲突分别是什么？
4. 开篇第一个悬念钩子是什么？（必须能勾住读者）
5. 高潮事件链：第一次大高潮发生在哪、爽点是什么？
6. 主角会面临哪些两难选择？（增加人物深度）

### 问答纪律

- 用户未回答的问题允许合理默认值，但默认值必须明确标注"（默认）"并在产出中可被用户一眼看出。
- 禁止把用户没说的设定写死进 book.md 后宣称是用户确认的。
- 每层答完展示摘要，用户确认后再进入下一层。

## 二、大纲规划

### 层级结构

```
全书大纲（主线 + 总字数 + 卷划分）
├── 第一卷卷纲（目标/起止章/高潮）
├── 第二卷卷纲
└── 前三章细纲（场景/冲突/章末钩子）
```

### 全书大纲模板

```markdown
# <书名> 大纲
预计总字数：<XX万>
## 主线
1. 起：...
2. 承：...
3. 转：...
4. 合：...
## 卷划分
| 卷 | 章节 | 目标 | 高潮点 |
|----|------|------|--------|
| 卷一 | 1-40 | ... | ... |
```

### 前三章细纲模板

```markdown
## 第一章 <暂定名>
场景：<地点/时间>
事件：<发生了什么>
冲突：<主角与谁的冲突>
章末钩子：<钩子内容 + 类型>
```

### 伏笔台账（plot_threads.md）

```markdown
# 伏笔与悬念台账
| 编号 | 伏笔内容 | 埋设章 | 预计兑现章 | 状态 |
|------|----------|--------|-----------|------|
| T01 | 主角玉佩的神秘力量 | 3 | 30 | 已埋设 |
```

状态枚举：已埋设 / 推进中 / 已兑现 / 已放弃。

### 钩子设计原则（Chinese Novelist 机制）

- 每章结尾必须有钩子，类型轮换：悬念钩 → 危机钩 → 奖励钩 → 信息差钩。
- 卷末章可用"大钩子"：改变局势的事件、身份反转、强敌登场。
- 钩子必须写进台账，否则视为无效伏笔，check_consistency.py 会报错。
