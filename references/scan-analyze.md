
# 扫榜拆文方法论

来源：整合 Oh Story 的"扫榜拆文去AI味"机制与网文圈通用拆文法。

## 一、扫榜选题

### 平台与榜单类型

| 平台 | 主要榜单 | 看什么 |
|------|----------|--------|
| 番茄小说 | 热门榜、新书榜、免费榜 | 新书趋势、免费市场偏好 |
| 七猫免费小说 | 热度榜、完结榜 | 免费长篇结构、题材生命周期 |
| 起点中文网 | 月票榜、收藏榜、新书榜 | 付费市场风向、精品题材 |

### 扫榜步骤

1. 明确目标：男频/女频？全品类还是固定品类？（通用网文下由用户每次指定）
2. 抓取榜单前 10-20 名：书名、作者、题材标签、简介、字数。
3. 统计题材分布 → 找"红海题材"（同质化严重）与"蓝海缺口"（少但有潜力）。
4. 点开 2-3 本头部书看开篇 2000 字：第一段是否直给冲突、金手指何时出现。
5. 产出 `memory/benchmark.md`，格式：

```markdown
# 榜单扫描 <日期>
平台：番茄/七猫/起点
| 排名 | 书名 | 题材 | 字数 | 开篇钩子 | 亮点 |
|------|------|------|------|----------|------|
...
## 题材分布
- 红海：都市 5 本、玄幻 4 本
- 蓝海：末世科幻 1 本
## 选题建议
1. 候选A：...（理由）
2. 候选B：...
```

## 二、爆款拆文

### 拆什么

首选对标书前 3 章（黄金三章），次选全书目录看结构。

### 拆解表

| 维度 | 要拆出的内容 |
|------|--------------|
| 开篇三要素 | 主角初始处境 / 第一个冲突 / 第一个悬念钩子 |
| 章节节奏 | 每 500 字：事件-情绪-冲突变化 |
| 钩子清单 | 章末钩子类型与强度 |
| 爽点结构 | 金手指、打脸、逆袭、收服的排列次序 |
| 人物弧线 | 主角前 3 章成长/获得/困境 |
| 世界观交代方式 | 直述 / 对话带出 / 行动展现 |

### 产出模板（memory/breakdown_<书名>.md）

```markdown
# 拆文：<书名>
来源：<平台/用户提供>
## 黄金三章结构
第一章：<场景-事件-章末钩子>
第二章：...
第三章：...
## 节奏模板（可复用）
- 第1章：交代处境(300字) → 冲突爆发(800字) → 第一次打脸/获得(1200字) → 钩子(结尾)
## 钩子类型清单
1. 信息差钩子：主角知道别人不知道的事（示例位置：章1）
2. 危机钩子：强敌/时限逼近（示例位置：章2）
3. ...
## 可借鉴点 / 避雷点
```

## 三、拆文反哺写作

- 大纲阶段：节奏模板直接映射到前三章细纲。
- 写作阶段：每次动笔前回看拆文表中的"钩子节奏"，避免水章。
- 去AI味阶段：拆文中标记的"口语化/强情绪表达"作为改写参照。

## 四、注意

- 榜单数据实时变化，务必标注扫描日期。
- 公开片段可参考，完整文本需用户授权获取；不得诱导侵权。
- 拆文是找规律，不是抄袭；产出模板为节奏参考，不复制具体文字。
