


# 去AI味规则与 AIGC 痕迹扫描

来源：整合 Oh Story 扫榜拆文去AI味思想 + 用户真实投稿踩坑记录（番茄/七猫 AIGC 标注反复回写问题）固化而成。

## 一、AIGC 痕迹全量扫描（强制门禁）

### 变体清单（必须全部覆盖）

| 类别 | 变体关键词 |
|------|-----------|
| 中文明示 | AI生成、AI 生成、内容由AI生成、内容由 AI 生成、由AI创作、AIGC、AI写作、AI 写作、人工智能生成、智能助手生成、生成于AI、AI辅助 |
| 英文/代码 | ContentProducer、content producer、Generated by AI、generated by AI、Generated with AI、Produced by AI、Made with AI、AI-generated、ChatGPT、GPT-4、Claude、Copilot、DeepSeek、LLM-generated |
| 免责声明 | 仅供参考、内容由AI生成仅供学习、本文由AI生成、以上内容由AI生成、如有雷同纯属AI |
| 平台标注 | 番茄AI标注、七猫AI标注、AIGC标注 |

### 扫描规则

1. **所有对外文件**：txt / md / docx 一律扫描。
2. **docx 特殊处理**：解包 zip，读 `word/document.xml` 全文（含隐藏文本、批注、页眉页脚路径），因为普通文本提取可能漏掉嵌入 XML 的标注。
3. **重写后必重扫**：任何转换、重写、格式调整后，AI 标注可能被回写，必须再次扫描。
4. **大小写/空格变体**：关键词匹配时忽略大小写与单词间空格差异（如 "AI生成" 与 "AI 生成"、"GeneratedbyAI"）。
5. 残留数 > 0 时禁止交付，输出每个命中文件 + 行号/位置 + 关键词。

### 手动复查点（脚本扫不到的场景）

- 图片水印中的 AI 标注（需 OCR 或目检）。
- 平台界面标注（非文档内容，无需清理，但需向用户说明）。
- 用户主动保留的免责声明（需用户确认是否保留）。

## 二、去AI味规则（Humanizer-zh 风格固化）

### 1. 消除"AI腔"高频词

写作与审稿时命中以下词/句式即标记改写：

- 万能副词连发："缓缓地""轻轻地""静静地""微微地""慢慢地"
- 抽象概括句："空气中弥漫着一种说不出的气氛""内心五味杂陈""时间仿佛凝固了"
- 强行文艺："如诗如画""岁月静好""仿佛一幅水墨画"
- 排比铺陈：连续三个以上"不是…而是…""既…又…"
- 生硬书面语："显而易见""综上所述""值得一提的是""与此同时"
- 翻译腔："他看起来似乎…""这听起来像是一个…的故事"

### 2. 化抽象为具象

| 抽象写法（改前） | 具象写法（改后示例） |
|------------------|----------------------|
| 他很紧张 | 他掌心全是汗，指节把衣角捏出了褶 |
| 她非常愤怒 | 她摔了杯子，碎瓷片崩到他脚边 |
| 场面十分尴尬 | 三个人都盯着地面，谁也没先开口 |
| 夜很深了 | 楼下的便利店关了灯，只剩烟头在黑暗里明灭 |

### 3. 制造个人化表达

- 给主角/配角设计口头禅与习惯动作，重复使用建立辨识度。
- 心理活动用短句、碎片化，模拟真实思绪而非完整论述。
- 对话允许口语、省略、打断，禁止全员"字正腔圆"。
- 感叹与疑问适度穿插，避免通篇陈述句。

### 4. 节奏与分段

- 战斗/紧张场景用短段短句，营造压迫感。
- 日常/情感场景用中等段落，留呼吸感。
- 单段不超过 200 字；对话一段一人，禁止两人对话挤一段。

### 5. 去AI味程度分级（供用户选择）

| 级别 | 适用范围 | 操作 |
|------|----------|------|
| L1 轻量 | 平台 AI 标注风险排查 | 只清 AIGC 痕迹变体，不改文风 |
| L2 标准 | 常规投稿 | 清痕迹 + 消除高频 AI 腔词汇 |
| L3 深度 | 追求自然手感 | 全量改写：具象化、个人化、节奏重构 |

## 三、执行流程（清理-重扫强制闭环）

1. 运行 `scan_ai_traces.py <目标>` 确认痕迹基线。
2. 运行 `deai_rules.py <文件>` 得到 AI 腔命中清单。
3. 按用户选择级别逐段改写。
4. **清理后必重扫（强制闭环）**：运行 `clean_ai_traces.py <目标>`。该脚本自动完成"清理 + 重扫"两步：
   - 文本文件：删除整行仅含标注变体的行（被删行会逐条列出供复核）；
   - docx：解包 `word/document.xml`，删除仅含标注文本的 `<w:t>` 节点，段落无正文则整段删除，其余结构保持；
   - 清理完成后立即自动重扫，残留 > 0 时退出码 1（禁止交付），0 残留才退出码 0。
5. 任何转换、重写、格式调整后必须再次执行第 4 步（平台标注会反复回写，单次清理不可信）。
6. 痕迹 0 残留 + AI 腔命中归零（或用户确认剩余项可接受）才交付。

> 本 Skill 内部 references 中的 AIGC 元数据样本块为分析素材，不属于对外交付物；复制整个 Skill 目录外发前需先移出样本块。

## 四、边界声明

- 去AI味只降低"被 AI 痕迹判定"的概率，不保证平台审核一定通过。
- 不得伪造虚假创作证据或声称作品完全非AI创作（尊重平台规则与诚实原则）。
- 用户作品的平台协议风险由用户自行评估。
